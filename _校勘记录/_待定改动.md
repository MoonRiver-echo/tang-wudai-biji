# 14 处非常规改动：逐条前后对照

第一类（31 处普通行升为标题）文字一字不动，仅加 `#` 标记，不在此列。以下 14 处涉及拆行、降级、订字或删行，逐条列出原文与拟改结果。

---

## 1. 《大唐新语》L351 — 篇题与正文黏连

**现状**（卷五开头第一行即正文，篇题「忠烈第九」被吃进句首，且多一个句号）

```
# 大唐新语卷五

。忠烈。第九李玄通刺定州，为刘黑闼所获，重其才，欲以为将。叹曰：“吾荷朝恩……
```

**拟改**

```
## 大唐新语卷五

### 忠烈第九

李玄通刺定州，为刘黑闼所获，重其才，欲以为将。叹曰：“吾荷朝恩……
```

删去的字符：句首的 `。` 与篇题中的 `。`。正文自「李玄通」起，一字未动。

# 附：另需留意的一点（非改动，仅告知）

《纂异记》《酉阳杂俎》等书中的韵文，底本按一句（或一联）一行排印，行间空行分隔。按「一个文本块＝一段」的规则切分，这些诗句会各自成为独立的段落文件。例如上文第 6 条「许生」篇中那首七律，将切成 4 个段落文件。

保持原样是忠于底本的做法，也可以改为：凡以「诗云：」「歌曰：」「赋诗曰：」等结尾的提示行，与其后连续的韵文行合并为一段。如需后者请说明。
