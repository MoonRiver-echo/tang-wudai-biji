志怪动物分类 · 关系模型

CSV / JSON / Markdown 是同一批段落的三种序列化。分号字段为多值标签， Markdown 树每层只取主标签。数据库保存全部标签，rank=1 即主标签， 并预留通用词表以容纳后续维度。

是“分面记录”，不是“层级树”。 志怪类别、皇帝·年号、事类、动物是四个独立维度；Markdown 的 L1→L2→L3→L4 只是一种浏览顺序。若把这棵树存成父子类目表， 「任意朝代下的所有龙」这类查询就需要递归遍历，新增维度（地点、人物） 也得改表结构。连接表 + rank 让两个方向都保持简单。

扩展设计

L1–L4 保持类型化

「开元年间 神仙佛道 类中的龙」需要真实外键，而不是通用标签包。 四个连接表保留；未来的新维度（地点、人物、母题）走 vocabularies / terms / paragraph_terms 通用词表。

用 rank，不加 is_primary 列

CSV 的顺序本身有意义：首项即 Markdown 树采用的主标签。 rank=1 为主，UNIQUE(paragraph_id, rank) 保序，无需冗余布尔列。

与 notes.db 的连接键

notes.db 已存全部 4204 段原文。本库是动物志怪子集， 用 books.name + paragraphs.para_no 即可关联， 不复制全文库。
